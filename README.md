# CS760 Group 2 — Crude Oil Direction Prediction

Does news sentiment add value beyond price for next-day WTI direction?

## Code
Four members are responsible for the coding work of the project:
- XiaoranSi_price_data_pipeline.py — price data collection, cleaning, features, label (Xiaoran Si)
- Zhengxin_sentiment_pipeline.py — CrudeBERT + LLM sentiment scoring (Zhengxin Yang)
- QuYueming_run_pilot_experiment.py — walk-forward pilot experiment (Yueming Qu)
- ChanghuaGuo_download_gdelt_news.py & ChanghuaGuo_clean_headlines.py — news data collection, cleaning (Changhua Guo)

## Note
The DeepSeek key is read from the environment variable DEEPSEEK_API_KEY.
